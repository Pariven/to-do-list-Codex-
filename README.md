# My Daily Space

A responsive React + Vite + TypeScript prototype for personal daily planning.

## Included in this milestone

- Responsive desktop sidebar and mobile navigation
- Dashboard with daily completion progress and upcoming tasks
- Task creation, editing, completion, deletion, search and status filters
- Task descriptions and attached memos
- Independent personal notepad with pinning and search
- Calendar month overview and daily agenda
- Light/dark mode and three live colour palettes
- Local browser persistence through `localStorage`

## Development

```bash
npm.cmd install
npm.cmd run dev
```

Build for production with `npm.cmd run build`.

Cloud sync, authentication, browser/native notifications, IndexedDB migration and Capacitor Android packaging remain intentionally configurable for the next phase, as requested in the specification.
